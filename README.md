# The Best Advice I Ever Got

One sentence about the best advice ever received, written by a small deterministic program.

> My older sister, lending me her last twenty, said, "Pay me back by never needing it again."

`main.ts` writes that line (91 characters) to `/output/entry.txt`. No network, no dependencies, no secrets — just Node's standard library.
